# English dependency parser assets

This application bundles the following local grammar-analysis assets:

- `english-ud-2.1-20180111.udpipe` — English UDPipe model from
  [bnosac/udpipe.models.ud](https://github.com/bnosac/udpipe.models.ud), trained
  on Universal Dependencies English 2.1 data. License: CC BY-SA 4.0. SHA-256:
  `20432A6F87B1F258927207B8FBD2DC21EBFF9722B381B7A36CEF34C8C9A380DC`.
- UDPipe WASM runtime — `udpipe-wasm` 0.1.0, MPL-2.0.

The model is used locally for tokenization, POS tagging, lemmatization and
Universal Dependencies parsing. No source article text is uploaded for this
local path.
