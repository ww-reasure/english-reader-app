# English Reader App: Maintainer Guide

## Scope and source of truth

- Treat this directory as the primary Git repository and Android application.
- Edit source in `src/`, `css/`, `public/`, and `android/app/src/main/`.
- `www/` and `android/app/src/main/assets/` are generated by the Capacitor build; do not edit them by hand.
- The Python/Flask code in `../server/` is a local/reference implementation. The shipping app uses the CloudBase article service configured in `src/config.js`.

## Architecture

- The client is a framework-free ES-module SPA. `src/app.js` initializes it and `src/router.js` owns hash routes.
- User settings (including the BYO AI key) live in `localStorage`; learning content and reading statistics use IndexedDB (`src/db.js`). Preserve IndexedDB migrations and existing store/index names.
- Articles come from the fixed CloudBase endpoint in `ARTICLE_SERVER_URL`. The reader list expects `/api/articles` and article details at `/api/articles/{id}`.
- CloudBase source is under `../server/cloudfunctions/`. `article-api` serves HTTP and `article-fetcher` is the scheduled ingestion function. Check both before changing the API contract or deployment configuration.

## Development and verification

```powershell
cd E:\play\claude\english-reader\mobile
npm run dev
npm run build       # writes www/ and synchronizes generated Android assets
npm run build:apk   # also invokes Gradle to create a debug APK
```

- There is no automated test suite yet. For a functional change, run `npm run build` and manually exercise the changed route in a browser or Android WebView.
- Before an APK release, keep `version.json` and `android/app/build.gradle` version name/code synchronized.
- Do not overwrite or discard uncommitted work. Start with `git status --short` and use focused diffs.

## Security and deployment

- Never hard-code user AI keys or CloudBase credentials. The client key is intentionally user-provided and device-local.
- Cloud function import/maintenance authentication must use deployment environment variables; do not distribute fallback secrets in source or logs.
- The repository CloudBase descriptor currently lists only `article-api`; confirm the scheduled `article-fetcher` deployment separately before changing production ingestion.
