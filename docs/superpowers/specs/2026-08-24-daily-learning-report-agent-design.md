# 内部学习 Agent 与每日学习日报设计

- 日期：2026-08-24
- 状态：已与用户逐段确认
- 目标分支：`feat/english-practice-machine`
- 适用范围：私有 English Reader App

## 1. 背景与目标

用户同时在本 App 和外部背词 App 中学习。外部 App 导出的 PDF 会把新学词和复习词放在一起，因此一次导入中：

- App 学习词库中不存在的词代表本次新增；
- App 学习词库中已经存在的词代表一次外部复习；
- 同一天重复导入同一个词不能重复计数或反复推进排期；
- 第二天再次导入时可以重新计为一次外部复习。

除导入外，App 已经积累阅读、正式复习、专项复习和真题练习数据。目标是建立一套本地、确定、可追溯的日级学习数据视图，使内部 Agent 能回答学习数据问题，生成当日总结，并输出可复制给个人 AI 助手的完整 Markdown 日报。

本功能的核心原则：

1. 数字由本地确定性代码计算，AI 只负责解释和建议。
2. Agent 通过有界、只读工具查询，不直接获得任意数据库访问权。
3. 页面统计、Agent 回答和日报复制共用同一聚合结果。
4. 外部复习可以适度调整正式排期，但不能冒充一次“认识”。
5. 辅助统计失败不得阻断正常阅读、查词或答题；正式排期更新必须事务一致。

## 2. 非目标

本期明确不做：

- 不在学习档案增加日报页、日报标签或生成按钮；
- 不做 Android 后台定时生成、晚间通知或自动弹窗；
- 不将 PDF 重复词直接映射为“认识”或“模糊”；
- 不让专项复习改变正式 SRS；
- 不让日报反向改写历史学习事实；
- 不向 AI 发送完整文章、完整试卷或任意数据库记录；
- 不为旧版本缺失的导入重复、查词或题型时长补造数据；
- 不修改公共分支、公开包或私有题包内容。

## 3. 当前能力与缺口

现有事实源包括：

- `learnWords`：正式 SRS 唯一事实源；
- `reviewEvents`：正式复习和专项练习的评分事件；
- `readingStats`：有效阅读、主动阅读秒数、词数和 WPM；
- `examAttempts`、`examResponses`、`examWrongStates`、`examTranslationReviews`：真题练习、正确率、错题和翻译复习状态；
- `LearningAgent`：已有学习概览、真题概览、待复习词和考试重点词等只读工具；
- 聊天消息已有复制能力。

当前缺口：

- 单词导入只返回成功新增数，重复词通过异常被静默丢弃；
- 没有导入批次、当日去重或外部复习证据；
- 阅读查词和阅读收藏缺少可按日期、文章和来源查询的活动记录；
- 闪卡、语境和专项复习缺少统一有效时长；
- 整卷真题只有总有效时长，无法归属到具体题型；
- Agent 的学习概览以累计总量为主，缺少统一的指定日期明细；
- 没有独立于聊天记录的日报快照和日报卡片协议。

## 4. 产品入口与交互

### 4.1 生成入口

首页输入框上方的横向快捷操作区新增“今日日报”，与“随机生成”“复习阅读”等按钮并列。学习档案不增加生成入口。

点击后：

1. 本地聚合器计算当天事实；
2. 若数据指纹未变化，复用已保存日报和 AI 分析；
3. 若数据变化，更新当天唯一日报并请求新的 AI 分析；
4. 在聊天流中显示日报卡片。

### 4.2 日报卡片

日报以助手消息中的折叠卡片展示：

- 折叠状态显示日期、核心学习总时长、阅读篇数、真题概览、词汇变化和一句总结；
- 点击卡片展开完整词汇、阅读、复习、真题、趋势和建议；
- 复制键保持在现有 AI 消息操作位置；
- 复制键复制完整 Markdown，不只复制折叠摘要；
- 当天继续学习后，旧卡片显示“有新学习数据”，再次生成更新同一日报；
- 聊天只保存 `reportId` 引用，不复制整份日报正文。

清空聊天只删除对话及卡片引用，不删除本地日报。日报不提供独立可见历史页面。

### 4.3 历史查询

用户可以在首页 Agent 中询问：

- “查看 8 月 20 日的学习日报”；
- “昨天导入了多少重复词”；
- “最近七天哪个题型最弱”；
- “今天有哪些词查了两次以上”。

Agent 通过只读工具查询并重新展示日报卡片。日报保留今天及之前 29 个本地自然日；超期后明确提示已过期，不从不完整数据中伪造完整日报。

## 5. 日期、词元与去重口径

### 5.1 本地自然日

所有“今天”“昨天”和趋势日期按设备本地时区计算，不能使用 `toISOString()` 的 UTC 日期作为日键。日键格式为 `YYYY-MM-DD`。

跨午夜的有效学习时间按实际发生时间拆分到两个日键。系统时区变化后，已经写入的事件保留原 `dayKey` 和写入时区偏移，不能重解释旧事件。

### 5.2 词元规范化

导入和日级去重使用与 `learnWords` 一致的规范化词元规则，至少统一空白、大小写和当前 `getStemForm` 结果。同一导入文件先按规范化词元去重。

### 5.3 每日导入信号

每日导入唯一键：

```text
import-word:<dayKey>:<normalizedLemma>
```

规则：

- 一个词每天最多接受一次成功的导入信号；
- 第一次导入时若为新词，只计新增，不计外部复习；
- 该新词当天第二次导入时归入“今日已处理”，不变成外部复习；
- 第一次导入时若已存在于学习词库，计一次外部复习；
- 第二天同一词重新获得一次导入资格；
- 处理失败不占用每日唯一键，允许重试；
- 阅读中先收藏的新词，如果当天之后第一次出现在 PDF 导入中，可以额外获得一次外部复习信号，因为这是不同学习场景的独立接触；
- PDF 先新增、随后阅读再次遇到时，新增仍只算一次，阅读活动记为再次遇到。

## 6. 单词导入 2.0

### 6.1 预分析

导入先提取、规范化、去重并查询本地状态，然后展示：

```text
识别到 76 个有效词
新增词             18
可计外部复习       42
今日已处理         14
无法识别            2
```

用户确认后才执行写入。完成结果保存：

- 识别唯一词数；
- 新增词及词元；
- 外部复习词及词元；
- 实际调整排期词；
- 原排期已更晚词；
- Recovery 中只记录接触词；
- 今日重复忽略词；
- 失败词和可读原因。

新词的词典查询失败时仍允许导入，保存“释义待补全”，不计为导入失败。

### 6.2 批次恢复

导入批次先保存 `in_progress` 状态和稳定 `batchId`。每个词成功后写入批次进度；页面退出或 App 被终止后可以按 `batchId` 恢复。已成功词依靠每日唯一键不会重复处理。

一个词失败不回滚整份 PDF；其余词继续。每个外部复习词的排期、事件和去重标记必须原子写入。

## 7. 外部复习调度

外部重复词使用独立的中等正向信号，不调用 Session Relearning，也不伪装为现有 1/3/5 评分。

### 7.1 资格

词必须满足：

- 在当前导入批次处理前已存在于 `learnWords`；
- 当天尚未成功接收导入信号。

### 7.2 信用公式

```text
creditDays = clamp(round(max(interval, 0) × 0.25), 1, 7)
candidateNextReview = now + creditDays
nextReview = max(existingNextReview, candidateNextReview)
```

其中无有效 `existingNextReview` 时以 `now` 为基线。

示例：

- interval 2 天：信用 1 天；
- interval 7 天：信用 2 天；
- interval 30 天：信用上限 7 天；
- 原排期已经晚于候选日期：不继续叠加延期。

### 7.3 不可改变字段

外部复习不修改：

- `interval`；
- `easeFactor`；
- 正式 `reviewCount`；
- `lastQuality`；
- `recoveryStage`；
- `recoveryTarget`；
- `lastDebt`；
- 直接回忆成功率或知识掌握概率。

允许更新：

- `externalReviewCount`；
- `lastExternalReviewAt`；
- 实际需要时的 `nextReview`；
- 仅当 `nextReview` 实际变化时增加 `reviewRevision`。

Recovery 或顽固词只记录外部接触，不延期、不降低阶段。`reviewEvents` 保存 `source: 'external-import'`、空正式评分、中等证据强度、是否调整排期和批次信息。

### 7.4 原子性

同一事务完成：

1. 重新读取词和当日去重键；
2. 更新允许的 `learnWords` 字段；
3. 追加外部复习事件；
4. 写入每日去重事件。

任一步失败时全部回滚，该词可以重试。

## 8. 学习活动事实源与补充事件

### 8.1 继续使用的现有事实源

| 活动 | 事实源 |
|---|---|
| 普通阅读 | `readingStats` |
| 真题题目与结果 | `examAttempts`、`examResponses` |
| 真题错题与翻译复习 | `examWrongStates`、`examTranslationReviews` |
| 正式 SRS | `learnWords`、`reviewEvents` |
| 专项练习评分 | practice review events |

### 8.2 新增存储 `learningActivityEvents`

数据库升级新增键为 `id` 的事件表，至少包含索引：

- `occurredAt`；
- `dayKey`；
- `type`；
- `sessionId`；
- 唯一 `dedupeKey`。

没有去重要求的事件不写 `dedupeKey`，允许唯一索引中存在多个缺失值。

事件类型：

- `word_import_batch`：导入批次状态和结果；
- `word_import_daily`：每词每日导入唯一信号；
- `reading_word_lookup`：成功打开释义；
- `reading_word_saved`：阅读收藏来源和文章；
- `review_session_summary`：闪卡、语境、专项复习时长和结果；
- `exam_active_slice`：真题单元/题型有效时间片；
- `ai_learning_interaction`：完成的学习 Agent 交互次数，只用于单独展示。

补充事件保存 35 个本地自然日，确保所有仍在 30 天保留期内的日报可以重新聚合。清理补充事件不触碰现有长期学习事实源。

## 9. 活动计时

### 9.1 核心学习总时长

计入：

- 有效阅读；
- 真题有效作答；
- 正式闪卡；
- 语境复习；
- 专项复习。

不计入：

- AI 对话停留时间；
- 单词详情页面停留时间；
- 页面后台时间；
- 超过现有闲置阈值后的时间。

AI 学习交互次数单独展示，不进入核心总时长。

### 9.2 计时切片

所有新增计时使用带 `sessionId` 的有效时间片。以下动作必须结算当前切片：

- 页面进入后台或失去可见性；
- 用户闲置；
- 切换真题单元或题型；
- 提交练习；
- 正常离开页面；
- 本地午夜到达。

切片写入使用稳定去重键，重复 flush 不得重复累计。

### 9.3 真题题型时间

`exam_active_slice` 至少保存：

- `attemptId`；
- `bankId`、`paperKey`、`unitKey`；
- 题型和 matching variant；
- `practiceKind`、`practiceOrigin`；
- 开始与结束时间；
- 有效毫秒；
- `dayKey`。

整卷中切换单元时归档前一单元。日报按考试、试卷和题型汇总。错题重做与专项练习单独标记，不计入“新做题”数量。

## 10. 阅读查词与收藏

阅读中首次收藏、学习词库原本不存在：

- 计入今日新增；
- 来源为阅读收藏；
- 保存文章 ID、标题和时间。

词已存在时再次收藏：

- 不计新增；
- 记录阅读再次遇到；
- 不自动改变 SRS。

成功打开释义时记录一次查词。相同文章/页面、相同词在 2 秒内的重复触发合并，加载失败、取消或未显示结果不记录。

日报统计：

- 查词总次数；
- 不同词数；
- 重复查询词及次数；
- 来源文章；
- 是否后来收藏。

只查词不加入学习词库，也不影响 SRS。

## 11. 每日聚合器

新增纯逻辑 `DailyLearningAggregator`，输入日期和各事实源数据，输出固定版本的 `DailyLearningReport`。

### 11.1 报告结构

```text
DailyLearningReport
├─ dateKey、timezoneOffset、schemaVersion
├─ completeness
├─ coreStudyDuration
├─ vocabulary
├─ reading
├─ wordReview
├─ exam
├─ trends7d、trends30d
└─ aiAnalysis
```

每个区域的完整性为：

- `complete`：数据完整；
- `partial`：升级前或会话中断，只能提供部分统计；
- `unavailable`：没有该类可用数据。

零和缺失必须分开表达。

### 11.2 词汇区域

- 今日新增唯一词；
- PDF 新增和阅读收藏新增；
- 外部复习词；
- 实际调整排期词；
- 原排期已更晚词；
- Recovery 中只记录接触词；
- 当日重复忽略词；
- 查词总次数、不同词数和反复查询词；
- 新增和外部复习词明细。

复制时词元默认全部列出；总数超过 100 时列前 100 个并注明剩余数量。排序稳定，优先按发生时间，其次按规范化词元。

### 11.3 阅读区域

- 有效完成篇数；
- 有效阅读总秒数；
- 总词数、平均 WPM；
- 每篇标题、难度、时长和 WPM；
- 阅读收藏和查词；
- 未达到有效阅读门槛的记录单列为未完成，不混入完成篇数。

### 11.4 单词复习区域

按正式闪卡、语境复习和专项复习分别汇总：

- 有效时长；
- 完成词数；
- 认识、模糊、忘记；
- 新进入 Fragile、Relearning、Difficult；
- Recovery 阶段减少；
- 顽固词；
- 专项范围及“不影响正式 SRS”标记。

### 11.5 真题区域

按考试、年份/试卷、题型三级展开，至少支持：

- 英语一完形填空；
- 英语一阅读理解；
- Part B 段落排序或匹配；
- 四级选词填空；
- 四级长篇阅读；
- 四级仔细阅读；
- 翻译；
- 整卷和单项练习；
- 新做题、错题重做和手动专项练习。

客观题显示作答、正确、正确率、有效时长和错题号。正确率分母只包含已经作答的客观题。翻译显示完成段数、有效时长和训练评价状态，不伪造成客观正确率。

### 11.6 趋势

日报以今天为主体，附带：

- 最近 7 天日均；
- 最近 30 天趋势；
- 当前待复习词；
- Recovery 词；
- 活跃错题。

AI 可据此识别学习量变化、题型正确率和耗时异常、反复查词及恢复负担。

## 12. 日报存储与失效

新增 `dailyLearningReports`，以 `dateKey` 为唯一键。记录：

- 确定性统计快照；
- `schemaVersion`；
- `dataFingerprint`；
- 完整性；
- AI 分析状态与正文；
- 完整 Markdown；
- 创建、更新时间和过期时间。

今天及之前 29 个自然日可用。清理日报不删除阅读、真题、SRS 等原始记录。

`dataFingerprint` 由参与聚合的稳定 ID、revision、更新时间和统计版本生成，不包含 API key 或完整内容。当天事实变化时：

- 旧卡片标记有新数据；
- 再次生成时重新聚合；
- AI 只在指纹变化后重新请求；
- 数据未变化时复用缓存。

## 13. Agent 工具与安全边界

新增只读工具：

### `get_daily_learning_report`

参数：有效本地日期。返回模型可理解的有界摘要，并可交付完整日报卡片 artifact。没有现成日报但日期仍在保留范围内时，按事实源生成；超期返回明确状态。

### `list_recent_learning_reports`

参数：`limit`，上限 30。只返回日期、核心摘要、完整性和更新时间。

### `get_learning_activity_detail`

参数：日期、受支持类别和有界 `limit`。类别限制为词汇、查词、阅读、复习、真题；不能指定数据库表、任意索引或任意代码路径。

安全要求：

- 工具只读，不能修改学习记录、导航或启动练习；
- 日期范围最多 30 天；
- 给模型的工具文本保持有界，完整明细通过 artifact 交付；
- 不发送完整文章、完整试卷或未请求的题干；
- 词元最多发送 100 个，超出只给数量和高频项；
- 错题默认只发送考试、年份、题型、题号和统计；
- 返回数据来源、统计版本和完整性；
- 系统提示要求区分事实、推断和建议，禁止编造缺失数据。

## 14. AI 分析与复制

本地聚合器先生成不可改写的事实数据。AI 只生成：

- 当日概括；
- 与 7 天日均和 30 天趋势的对比；
- 薄弱题型、耗时异常、反复查词和 Recovery 负担；
- 2–4 条次日建议。

AI 请求失败、取消或返回空内容时，数据日报仍可展开和复制，智能分析区域显示暂不可用，失败结果不缓存为成功。

复制正文使用稳定 Markdown：

```markdown
# 英语学习日报｜YYYY-MM-DD

## 今日概览
## 词汇
## 阅读
## 单词复习
## 真题训练
## 近期趋势
## 总结与明日建议
```

## 15. 隐私、错误与兼容性

### 15.1 隐私

- 原始学习记录保存在本机；
- AI 只接收聚合结果和完成分析所需的有界明细；
- 不发送 API key、完整数据库、完整文章或完整试卷；
- 日报清理与清空聊天相互独立。

### 15.2 错误处理

- 查词、收藏和辅助计时写入失败不能阻断主操作；
- 失败被记录为统计完整性问题，不显示为零；
- 外部复习使用事务，禁止部分更新；
- 日报聚合某一区域失败时其他区域继续生成，并标记该区域不可用；
- AI 失败不损坏本地事实快照；
- 旧聊天引用的日报过期后显示“日报已过期”，不保留幽灵副本。

### 15.3 兼容性

- 数据库升级只新增存储和字段，不批量重写旧记录；
- 旧阅读、真题、词汇和 SRS 继续可读；
- 旧记录缺少新增遥测时标为 `partial`；
- 正式 SRS V2、Recovery、评分更正和 revision 守卫保持；
- 专项练习仍只记录 practice 事件，不改变正式 SRS；
- 现有学习档案页面继续使用现有长期统计，不增加日报 UI。

## 17. 测试与验收

### 17.1 导入与调度

1. 同文件重复词只识别一次。
2. 大小写和规范化词形按同一词元处理。
3. 新词第一次导入只计新增。
4. 新词当天第二次导入归入今日已处理。
5. 旧词第一次导入计外部复习。
6. 旧词当天第二次导入不计数、不改排期。
7. 第二天同一词重新可计外部复习。
8. 阅读先收藏、PDF 后导入时允许独立外部复习。
9. PDF 先新增、阅读后遇到时新增只算一次。
10. interval 2、7、30 天分别得到 1、2、7 天信用。
11. 原排期更晚时不额外推远。
12. Recovery 和顽固词只记接触，不延期。
13. 外部复习不修改 interval、ease、正式 reviewCount 和 Recovery 字段。
14. nextReview 实际变化时 revision 增加，否则不增加。
15. 外部复习事务失败后无部分写入并可重试。
16. 批次中单词失败不阻断其他词。
17. 中断恢复不重复处理已成功词。

### 17.2 活动与计时

18. 成功显示释义才记录查词。
19. 相同词 2 秒内重复触发合并。
20. 收藏新词和再次遇到正确区分。
21. 后台和闲置时间不累计。
22. 重复 flush 不重复累计。
23. 跨午夜时间切片正确拆日。
24. 整卷切题型后时间归属正确。
25. 进行中练习不计为已完成。
26. 评分更正不产生第二次复习。
27. 专项练习时长可统计但不改变 SRS。

### 17.3 日报聚合

28. 同一新增词跨来源只计一次。
29. 阅读有效完成和未完成分开。
30. 核心总时长只含五种有效学习活动。
31. AI 对话次数不进入核心时长。
32. 客观正确率分母只含已作答题。
33. 翻译不产生伪客观正确率。
34. 新做题、错题重做和专项练习分开。
35. 各考试、年份、试卷和题型正确展开。
36. 词元超过 100 时稳定截断并注明总数。
37. 旧数据返回 partial，不把缺失显示为零。
38. 7 天日均和 30 天趋势使用本地日键。
39. 数据指纹不变时复用 AI 分析。
40. 当天新增数据后更新同一日报。

### 17.4 Agent、卡片与保留

41. 首页快捷按钮生成折叠日报卡片。
42. 展开显示完整内容，复制得到完整 Markdown。
43. 清空聊天不删除本地日报。
44. 按日期查询可重新展示卡片。
45. 工具日期和 limit 越界被拒绝。
46. Agent 工具不能写库或导航。
47. AI 失败时数据版日报仍可用。
48. 超期日报和旧卡片显示明确过期状态。
49. 30 天日报清理和 35 天补充事件清理不影响长期学习记录。
50. 工具长结果不会截断本地复制正文。

## 18. 完成标准

功能完成必须同时满足：

1. 用户能在首页一键生成确定性今日日报；
2. Agent 能按日期回答词汇、阅读、复习和真题细节；
3. 折叠卡片可展开，现有复制位置能复制完整 Markdown；
4. 外部重复词每天最多一次，并按确认公式有限影响排期；
5. 真题按实际题型列出题数、正确率、错题号和有效时长；
6. 清空聊天不删除日报，30 天后按规则过期；
7. AI 不可用时本地数据仍准确可用；
8. 旧数据、Recovery、专项复习和现有学习档案没有行为回归；
9. 全量测试与私有 QA 构建通过。
