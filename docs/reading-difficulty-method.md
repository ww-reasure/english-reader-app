# 阅读难度、词库与个人匹配方法

本文说明当前 App 如何生成“目标考试导向阅读”，以及这些判断的边界。它不是“真题等值”声明，也不把一次初测、收藏或加入词库当成用户已掌握的证明。

## 1. 两个相互独立的选择

- **目标考试**：四级、六级、考研英语一、考研英语二。它决定材料的训练方向，不会因一次答题或阅读反馈被系统自动改写。
- **材料压力**：巩固、对标、加压。它分别对应 `97–98%`、`95–97%`、`92–95%` 的材料目标覆盖率范围。该范围是生成目标，不是对用户词汇量或真实掌握覆盖率的结论。

历史“考研”文章继续保留旧标签；后续生成必须选择英语一或英语二。

## 2. 离线、可追溯的词库

词库随 APK 一同安装，公共词库与个人 IndexedDB 学习记录分离。构建产物与来源清单位于：

- `public/data/lexicon-core.json`
- `public/data/lexicon-manifest.json`
- `public/data/oewn-core-2025.json`
- `public/data/oewn-artifact-manifest.json`

每个可用来源都记录 URL、固定版本、许可证、获取日期、SHA-256、用途和署名。当前职责如下：

| 层 | 用途 | 不能替代的内容 |
| --- | --- | --- |
| Open English WordNet | 独立按需加载的 exact lemma/POS 英文义项结构 | 不单独作为中文学习义真值，也不参与频率、CEFR、考试或难度计算 |
| NGSL | 通用高频词频层 | 不是四、六级官方词表 |
| NAWL | 通用学术词层 | 不是特定考试的真题词表 |
| wordfreq 3.2.0 | 查词候选与常用度补充层 | 不替代 NGSL/NAWL，也不参与文章难度硬约束 |
| CEFR-J Vocabulary Profile | CEFR 参考层 | 不等同于中国考试等级 |
| ECDICT 固定完整快照 | 中文学习义候选与词形补充 | 不整包导入，也不作为唯一真值 |

词条会标记为：

- **高可信**：来源、词性和常用中文学习义均经过构建校验，可离线直接显示。
- **离线筛选**：固定来源、单词形式、词性和常用中文义均通过自动筛选，可离线直接显示；它不是人工逐条审核的高可信义。
- **受限**：只保留词形、频率或英文结构；中文释义通过在线词典 / AI 临时回退，不写回静态词库。
- **拒绝收录**：缩略语、专名或优先专业义等不用于普通释义或难度判断。

`wordfreq` 只补充常用单词的离线查词候选范围和展示信息，保留前 25,000 个规范化单 token；NGSL/NAWL 仍是覆盖率与文章生成的主频率层。词形表也会记录产生规则。生成或解析时优先按本地 UDPipe 的 lemma 和词性匹配，因此 `students` 与 `student`、`met` 与 `meet` 不会被当成三个独立生词；专名、数字和标点不进入个人词汇覆盖率分母。

## 3. 冷启动与个人证据

初次校准由 24 道按词频层分层的自适应词义题和一篇短阅读理解组成。答对只记为“暂定掌握”，不会立即产生 `92–98%` 的个人覆盖率承诺。完成初测后，界面和生成提示都显示为“证据收集中”。

可用于个人画像的证据是：

- 未展示释义时的直接回忆、测评答案或复习评分；
- 查词、看答案后评分和“忘了”等负向证据；
- 间隔或不同场景的再次答对，用于将单词从暂定掌握提升为稳定掌握。

收藏、加入学习词库和仅打开页面不会增加掌握概率。主动完成、正文浏览至少 70%，且前台阅读时间不少于 `max(45 秒, 词数 ÷ 400 词/分)` 的阅读，才会作为观察性阅读记录。跳过初测的用户先进入保守模式；完成三篇这样的有效阅读后仅询问一次“偏难 / 合适 / 偏易”。

在每个候选文章使用到的每个词频层都有足够直接证据（当前为至少 12 条、置信度至少 `0.60`）前，系统不会启用覆盖率硬门。启用后使用 **Wilson 95% 下界**，而不是乐观的后验均值，计算预计掌握覆盖；未被词库解析的词按零已掌握处理。

## 4. 生成与校验链路

1. 根据目标考试和材料压力形成受控规格；用户文字中的明确考试和字数要求会先归一化。
2. 生成文章后，离线词库检查词频、学术层、CEFR 层和来源完整性。
3. 本地 UDPipe WASM 在 Web Worker 中解析词元、词性和依存关系；它的初始化、取消与超时均有明确状态。
4. 字数和平均句长是当前硬性规格。句法观察范围、学术词比例和目标考试方向目前只记录与提示，不会伪称为已由历史真题语料校准的硬阈值。
5. 本地解析不可用时，才使用严格 JSON 的 AI 语法复核，并在报告中标记为 `ai_fallback`。文章仍要经过一次精修和再次校验；失败或取消时不保存为阅读卡片。

## 5. “真题难度”的边界

`public/data/track-baseline-registry.json` 记录目标轨道的研究参照与授权状态。当前注册表明确为 **provisional**：没有把原始考试文章放入 APK，也没有用未获许可的语料构造“重点词层”或 UDPipe 阈值。

因此产品表述应为“目标考试导向阅读”，而不是“等同真题”或“通过真题难度验证”。只有在获得允许的原始语料、固定快照及校验和、可复现的同分词 / UDPipe 统计、每轨样本分布报告和方法审核后，注册表才可以激活句法或目标词层的硬校验。

## 6. 可复现与更新

词库构建会验证来源字段、许可证、校验和、词条结构、词形映射及输出版本。高频词、学术词、四条轨道、词形、多词性和异常词均有回归测试。词库修正以新版 APK 下发；个人学习记录保留在 IndexedDB，不会因公共词库更新被删除。

开发验收至少运行：

```powershell
npm run lexicon:build
node --test tests/*.test.mjs
npm run build
```

正式发布还应在 Android 真机验证离线查词、UDPipe 首次初始化、解析取消、AI 降级标记和 APK 体积增量。
