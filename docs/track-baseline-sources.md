# 目标考试轨道：可审计基线登记（暂定）

本文件和 [`public/data/track-baseline-registry.json`](../public/data/track-baseline-registry.json) 的目的，是把“有官方考试导向”与“已有可复现真题统计”严格分开。当前登记为 **provisional / pending**，不参与文章生成、词汇重点层或本地语法阈值校验。

## 当前结论

目前尚未接受任何可随 App 分发或可在构建机重跑的四级、六级、英语一、英语二历年阅读原文语料。原因不是缺少网上的“真题整理”，而是这些网页、题库或 GitHub 仓库通常无法同时证明：原始授权、完整年份范围、固定版本、再分发许可和可复现分词过程。

因此当前界面和生成说明只能称为“目标考试导向阅读”，不能称“接近真题难度”“真题同等难度”，也不能依据旧 `exam-frequency.json`、`exam-words.json` 或网上抓取的题干建立考试重点词层。

## 可引用的开放聚合统计

两篇论文本身均以 CC BY 4.0 发布，因此可以保存其**归纳出的聚合数值和出处**，但这不等于获得论文所使用的考试原文。

| 覆盖轨道 | 开放来源与范围 | 可保留的聚合证据 | 不可直接拿来作 App 阈值的原因 |
| --- | --- | --- | --- |
| 四级、六级 | [Liu et al., 2023, DOI 10.3389/fpsyg.2023.1171227](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2023.1171227/pdf)。2013-12 至 2021-12，阅读 A/B/C，四级、六级各 51 套、204 篇；分别为 107,386 / 127,143 running words。 | 论文报告的 AWL 覆盖率：四级 6.60%，六级 7.44%。 | 这是 AWL 与 Flesch–Kincaid 的研究口径，不是本 App 的 NAWL 层，更不是 UDPipe 依存深度、从句率、被动率或非谓语率。 |
| 英语一、英语二 | [张玲、时真妹，2023，DOI 10.12677/CES.2023.111008](https://pdf.hanspub.org/ces20230100000_48636844.pdf)。2018–2022 阅读 A，各 20 篇。 | 论文支持“英语一、二在部分词汇长度、总篇章长度、传统可读度上有差异”，但句法差异不能据此简单断言；论文报告的总阅读 A 篇组长度均值为 1699.2 / 1623.2。 | Coh-Metrix 的 PCSYN 不是本 App UDPipe 指标；论文的“篇组长度”也不是一篇 App 文章应有的字数。 |

两份下载论文的 SHA-256、下载日期、许可证、样本范围和限制都记录在注册表中。它们只用于维护者人工审计与未来统计的合理性检查，注册表的 `activeForGeneration` / `activeForValidator` 都必须保持 `false`，直到满足激活门槛。

## 激活为真实统计基线前必须完成

1. 获得可证明授权的原始阅读材料，或由权利人书面允许仅在内部构建环境处理；绝不把原文发进 APK。
2. 为每个来源保存版本、许可、获取日期、SHA-256、样本年份、篇数和排除规则；没有任何一项即不能激活。
3. 使用与 App 完全相同的 tokenizer、词形还原和 UDPipe 模型，批量生成四条轨道的词汇层、依存深度、从句、被动、非谓语、句长等分布，并固定构建脚本版本。
4. 在 APK 中只内置派生统计（样本量、分位数、来源摘要、脚本和数据哈希），不内置题干、答案、选项或可还原的 n-gram 表。
5. 由人工复核后，把对应轨道标为 `active-derived-statistics`；届时才能将**同口径**指标接到 `difficulty-profile` 和语法校验器。

在此之前，现有字数、句长和语法范围只是产品训练策略，不应写成“真题统计阈值”。用户的阅读覆盖率推荐则独立来自个人掌握证据，不能由这份暂定基线替代。

## 可执行来源审计

在每次词库或轨道数据改动后运行：

```powershell
npm run track-baseline:verify
```

该命令读取 `track-baseline-registry.json` 和词库来源目录中的四个 `target-focus-*` 占位项。它会拒绝以下情况：仅把公开网页或论文引用改标为激活、没有来源/派生 SHA-256、没有许可或授权记录、没有同 tokenizer 与 `udpipe-dependency-v1` 指标、没有每轨样本量与分位数，或将题干、答案、选项、可还原 n-gram 表放入发布物。

当前预期输出是 `Target-track baseline: disabled`。这不是构建失败，而是对“没有合格语料就不激活”的可执行确认。未来如获得权利人许可，构建产物仍只能保存不可还原的派生统计；原文始终不随 APK 分发。
